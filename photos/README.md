# Photos

写真は `photos/inbox/` に入れてから整理します。
「写真整理して」または「inbox処理して」と依頼すると、内容を確認して日付・カテゴリ別に移動します。

## 入れ場所

```text
photos/inbox/
```

## 分類先

写真は以下の形式で保存します。

```text
photos/YYYY/MM/DD/category/
```

カテゴリ:

- `arrival/`: お迎え、初対面、車移動、自宅到着、記念撮影
- `garden/`: 庭遊び、探索、日向ぼっこ
- `sunflower/`: ひまわりの発芽、成長記録、花
- `indoor/`: クレート、ソファ、お昼寝、おもちゃ
- `walk/`: 初散歩、公園、外出
- `vet/`: 動物病院、診察、体重測定

例:

```text
photos/2026/06/09/arrival/
photos/2026/06/09/garden/
photos/favorites/
```

## 書類写真

ワクチン証明書、血統書、マイクロチップ書類、保険書類、領収書は `medical/documents/` 配下へ整理します。

## お気に入り

表情が良い写真、成長記録として重要な写真、初体験イベント、家族写真、SNSアイコン候補は `photos/favorites/` にコピーします。

## 日記

写真整理後、写真から分かる内容を `daily-log/YYYY-MM-DD.md` に追記します。
