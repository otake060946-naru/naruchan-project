## Classic側チャットの主題

「まず動くものを作りながら、最終的に全部入りを目指す」設計として、Naru Life OS を Codex に渡すための要件定義。

## プロジェクト名

Naru Life OS

## 概要

ユーザーは ChatGPT を日常の相談相手として利用しており、現在は以下を ChatGPT との会話で行っている。

- ペット管理
- 写真管理
- Instagram投稿作成
- 購入履歴管理
- 健康管理
- 日記管理

これらを統合した AI ライフログシステムを開発する。

## 開発方針

- 最初から完成形を想定して設計する。
- 実装は段階的に行う。
- まず MVP を作成し、その後機能を拡張する。

## 最終目標

ユーザーは以下を行うだけでよい状態を目指す。

- 写真をアップロードする
- 動画をアップロードする
- ChatGPT に相談する

AI が自動的に以下を行う。

- 保存
- 分類
- タグ付け
- 要約
- 記録
- 編集
- 検索

## 技術要件

- Frontend: Next.js、TypeScript、Tailwind CSS
- Backend: FastAPI
- Database: SQLite 初期、将来 PostgreSQL
- Storage: ローカルストレージ、将来 S3 対応
- AI: OpenAI API
- 認証: ローカル認証、将来 Google 認証

## 必須機能

### ChatGPTチャット

- ChatGPT APIを利用
- 相談
- 質問
- 会話保存
- 画像添付
- 動画添付

### 会話管理

保存内容:

- 日時
- ユーザー発言
- AI回答
- 添付画像
- 添付動画

### AIメモリー

会話から重要事項を抽出して保存する。

例:

- 「なるちゃんは音に敏感」から `character_traits` へ保存
- 「リード購入」から `purchase_history` へ保存

### 写真管理

対応形式:

- jpg
- jpeg
- png
- heic

AI画像解析で以下を自動抽出する。

- 被写体
- 場所
- イベント
- 感情
- 行動

タグ例:

- dog
- whippet
- garden
- sunflower
- sleeping

### 写真整理

`photos/inbox` に投入された写真を自動処理し、以下へ分類する。

- arrival
- garden
- sunflower
- indoor
- walk
- vet
- documents

### 重複写真処理

重複判定時の保持優先順位:

1. 最新更新日時
2. 高解像度
3. 大容量

古い写真は削除候補として扱い、最新を残す。

### お気に入り管理

基準に合う写真を自動選定し、`favorites` へコピーする。

基準:

- 表情
- 記念日
- 成長記録
- SNS向き

### Instagram機能

画像選択後、AI が以下を生成する。

- キャプション
- ハッシュタグ
- 投稿候補

### SNS画像作成

対応先:

- Instagram
- Slack
- X
- Threads

機能:

- 正方形化
- トリミング
- コラージュ
- テキスト追加

### AI画像編集

自然言語で画像編集する。

例:

- 背景を富士山にする
- 不要物を消す
- 明るくする
- SNS向けに加工
- アイコン用にする

### 動画管理

対応形式:

- mp4
- mov
- m4v

動画解析で以下を抽出する。

- 登場人物
- 動物
- 行動
- 場所

自然言語で動画編集する。

例:

- 30秒にまとめる
- 可愛いシーンだけ抽出
- リール用縦動画
- 字幕追加
- BGM追加

### ペット管理

管理対象:

- 犬
- 猫
- その他

### 医療管理

保存対象:

- ワクチン
- 病院受診
- 体重
- 投薬
- フィラリア
- ノミダニ

書類画像から自動抽出する。

### 購入履歴管理

会話またはレシート画像から以下を抽出して保存する。

- 商品名
- 金額
- 日付
- カテゴリ

### 日記生成

毎日、以下から日記を自動生成する。

- 写真
- 動画
- 会話
- 医療記録
- 購入履歴

### タイムライン

日付順で表示する。

例:

2026-06-09

- なるちゃんお迎え
- 庭デビュー
- ひまわり観察
- 初日の食事

関連する写真、動画、会話を紐付ける。

### 自然言語検索

検索例:

- ひまわりの写真
- 初日の記録
- ワクチン履歴
- リード購入履歴
- 庭を走っている動画
- Slackアイコン候補

### 自動化

画像追加時:

1. AI解析
2. タグ付け
3. 分類
4. DB登録
