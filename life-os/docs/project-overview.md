# Naru Life OS

## 概要

ChatGPTとの会話を中心としたAIライフログシステム。

現在の主用途

- なるちゃん（ウィペット）の管理
- Instagram投稿作成
- 写真管理
- 動画管理
- 購入履歴管理
- 健康管理
- 日記管理

ユーザーは

- 写真をアップロード
- 動画をアップロード
- ChatGPTへ相談

するだけ。

AIが自動的に

- 保存
- 分類
- タグ付け
- 要約
- 記録
- 編集
- 検索

を行う。

---

# 現状認識

フル機能版は大規模プロジェクトとなる。

開発コスト

- OpenAI API
- ChatGPT課金
- Codex利用制限
- 個人開発時間

を考慮し段階的に開発する。

## 写真・動画管理

### 写真運用ルール

- 写真は `photos/inbox/` に入れてから整理

- 保存形式: `photos/YYYY/MM/DD/category/`
- 分類カテゴリ:
  - `arrival/`: お迎え、初対面、車移動、自宅到着、記念撮影
  - `garden/`: 庭遊び、探索、日向ぼっこ
  - `sunflower/`: ひまわりの発芽、成長記録、花
  - `indoor/`: クレート、ソファ、お昼寝、おもちゃ
  - `walk/`: 初散歩、公園、外出
  - `vet/`: 動物病院、診察、体重測定
- お気に入り写真:
  - 表情が良い写真
  - 成長記録として重要な写真
  - 初体験イベント
  - 家族写真
  - SNSアイコン候補

### 書類写真・レシート
